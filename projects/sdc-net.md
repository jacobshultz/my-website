I'm currently working with Dr. Ohl to develop a low-cost multi-view camera system for what will one day be UPJ's very own XR lab.

I've engineered a network cluster on a managed VLAN switch with isolated components. A dual-homed controller node acts as a gateway, provides DHCP and NAT to camera nodes.

I've also automated with Ansible. The entire depolyment solution is containerized.

I'm now working to develop a python library to facilitate synchronized image capture across nodes.
